# FRTB Risk Engine

A small self-contained market risk engine with a fixed portfolio and the project-defined factor model.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Notes

- This repository is intended for public GitHub use.
- Local secrets and generated artifacts are excluded via `.gitignore`.
- Keep market data proxies and output files out of version control unless intentionally shared.
